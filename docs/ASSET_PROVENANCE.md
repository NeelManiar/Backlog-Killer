# BK v0.2 originality and asset provenance

All v0.2 character artwork is authored in this change as React Native View geometry in `src/components/motivation.tsx`. No external character images, tracing, stock mascots, image generation, or downloaded artwork were used. No existing app or branded character was used as a character-design reference. The existing BK1–BK4-inspired application palette/layout is retained separately from the new characters.
